# Neo Voxels
Hello!

This is an edited version of Rethinking Voxels, which is a version of the Complementary shader packs adding things such as ray traced lighting and voxelization.

## How to Install

To install this shaderpack, you need to have minecraft 1.19.2 or later (older versions may work, but are unsupported), and the [Iris](https://irisshaders.dev) shader loader is highly recommended, although I will try to work on some other, more specialized ones. At the moment, I would recommend you refrain from reporting bugs that only occur with testing versions of these loaders.

Once you have your shader loader installed, you can clone this repository into your shaderpacks folder, and maybe at some point, download it directly from Modrinth.

you can find your shaderpacks folder by opening minecraft with Iris installed, navigating to `Options` -> `Video Settings` -> `Shader Packs` -> `Open Shader Pack Folder`. You can also drag-and-drop the zip archive in the shader selection menu to install it.
